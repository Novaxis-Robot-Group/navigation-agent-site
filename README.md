# Navigation Agent 官网

面向外部开发者和客户的中英双语产品介绍网站。首页默认英文，右上角可切换中文；重新打开或刷新页面回到英文。包含产品介绍、带关键节点的 MuJoCo 与 Go2 回放，以及项目代码和技术文档入口。

- 在线网站：[Navigation Agent](https://novaxis-robot-group.github.io/navigation-agent-site/)
- 网站源码：[navigation-agent-site](https://github.com/Novaxis-Robot-Group/navigation-agent-site)
- Agent 项目：[navigation-agent](https://github.com/Novaxis-Robot-Group/navigation-agent)

这是独立维护的静态网站，只需浏览器和 Python 3，不依赖 Node.js、Agent 服务或机器人环境。在 Mac 本仓库的 `main` 分支直接开发。

## 本地预览

在本仓库根目录运行：

```bash
python3 preview.py
```

打开 <http://127.0.0.1:4173/#videos>，在首页“视频演示”区域查看任务回放。预览服务支持视频分段读取（HTTP Range），可直接跳转到未播放的节点。普通 `python3 -m http.server` 不支持完整的录像跳转。

页面只保留顶部导航，滚动时始终吸顶显示。章节跳转会避开导航栏；手机换行及语言切换后按实际高度调整。首屏桌面左侧显示标题、说明和演示 / GitHub 入口，右侧为无边框 SVG 导航示意；窄屏改为居中的上下布局。不显示录像预览卡或左侧目录。示意不代表实测轨迹，不显示说明或按钮文字；点击画面可暂停 / 继续，支持键盘操作、离开首屏自动暂停和系统减少动态效果设置。任务锚点可直接分享，例如 `/#go2-bin`。

页面固定使用鼠尾草绿与烟灰蓝的莫兰蒂亮色风格，不提供主题切换或保存主题偏好。右上角仅保留语言切换。顶部“技术报告”在新标签中使用浏览器原生 PDF 预览；安装与接入步骤通过页脚“技术文档”链接查看，官网不展示快速开始或部署代码区。

## 技术报告

报告原文件位于 `media/reports/nova-hei-2026-10-22.pdf`，不依赖第三方阅读器，不设置强制下载。首页导航提供入口，评测口径内的链接定位到第 9 页实验计划。`media/` 已包含在 GitHub Pages 的触发路径和发布清单中。

报告中的 Nova-N 是本页 Navigation Agent 对应的导航原型，Nova-HEI 是其具身应用框架。当前范围是单机器人目标搜索与接近；多机器人、无人机、机械臂和跨任务记忆均不是已实现能力。首页保留现有布局，只同步任务内证据记忆、可选 YOLO-World 监测、事件调度及单独完成核验的边界。2026-10-22 版本的实验部分仍为计划，没有可替换示例表格的实测结果。

更新报告时使用新的版本文件名，同步修改首页链接，并运行 `node --test tests/*.test.cjs`。打开导航入口后，应看到浏览器中的 PDF 页面，而不是下载提示或 404。

导航下划线随当前章节更新。播放器使用统一的播放按钮、倍速控件和分段视角切换；决策列表用细线连接编号节点，区分已播放、当前与未播放节点。悬停或聚焦节点可查看说明，点击节点跳转录像。动效仅用于操作反馈，跟随系统的减少动态效果设置。

首页按“首屏介绍与行动按钮 → 工程架构 → 三项 Agent 能力网格 → From a goal to exploration → See it in action → Benchmarks”组织。效果演示包含 MuJoCo 方法对比和 Go2 真实场景两个小节。MuJoCo 顶部提供 缩略图与目标名称选择器，默认仅显示篮球任务；点击或使用方向键、Home / End 切换，手机可横向滑动任务卡片。切走时暂停旧任务，保留进度、视角和倍速，返回时不自动播放。任务锚点可直接打开对应任务，切换卡片不修改首页锚点。Go2 同样通过顶部两张任务卡片切换，桌面单卡与 MuJoCo 等宽，两张靠左排列，右侧留空，缩略图与 MuJoCo 一致，使用任务完成时的单张机器人相机画面。切走同时暂停两路、取消缓冲续播并保留进度和倍速，不影响 MuJoCo 任务选择。目标名称仅在选择器中显示，不重复任务大标题或 Task 编号。桌面左侧为 VLN 回放（未录制任务保留占位），中间为 Agent + VLN 回放，两种方法之间用竖线分隔；右侧常驻 Agent 节点与决策。两个视频等宽、同为16:9。平板将决策放到双视频下方，手机改为上下排列。“篮球”“床”和“冰箱”任务已加入纯 VLN 双视角录像，每次展示一项；各任务支持独立播放、进度、视角切换和倍速。每项的倍速与视角分别收在各自的更多设置面板中，首次加载默认 4×，录像仅在播放或跳转时加载。卡片不显示顶部状态栏；不在画面中央显示播放提示，可点击画面或画外控制轨播放。短录像结束后停在末帧，另一条继续播放；不拉伸时长或强行对齐事件。Go2 展示同一任务的实拍视角（External camera）、相机视角（Robot camera）与 Agent 节点；已接入“走到银色垃圾桶旁”和“走到茶水间吧台”的双视角录像与复盘节点，两路共用任务时间轴、播放和倍速；实拍未覆盖的时段显示提示。Go2 仅展示这两个任务，已移除饮水机和会议室占位。两个视角合并为左右分屏播放器，共用底部的一套播放按钮、进度条、倍速和全屏；手机也保留左右分屏，节点放在下方。全屏在浏览器支持元素全屏时同时显示双视角；仅支持视频原生全屏的设备回退到机器人相机。不与 VLN 对比。回放使用浅色面板，选中状态使用鼠尾草灰绿，组件统一为圆角卡片，标题和卡片边缘对齐，整个对比区与全站内容统一为桌面最大宽度 1200px。节点列表常驻；说明以贴着节点的浅色气泡按需显示。悬停或键盘聚焦可查看，点击节点同时跳转并保持气泡；点击外部、关闭按钮或按 Esc 收起。

确认视频可播放、节点可跳转、切换视角后保留进度，即回放预览成功。修改后刷新浏览器；按 `Ctrl+C` 停止服务。

播放器使用画面下方固定窄控制轨：桌面 40px，手机与触屏 44px。主控为播放、时间、细进度、全屏和更多；更多设置只保留倍速与视角，不显示关键节点分组或前后跳转按钮；跳转使用进度条或右侧决策列表。桌面悬停、Tab 聚焦、主动加载与错误时显示主控，暂停时保留播放入口；触屏常显。设置面板默认在画面外向下展开，必要时滚动页面腾出空间，并限制在视口内；仅在全屏时允许主动打开的设置面板临时覆盖角落。Esc、点击外部、焦点离开或切换任务可关闭，Esc 将焦点返回更多按钮。MuJoCo 两路独立，Go2 双视角共享，显隐不改变画幅或页面高度。

修改 Go2 播放逻辑后，可用 Node.js 运行 `node --test tests/go2-replay.test.cjs`。测试检查双路缓冲、4× 同步、1× 播放、取消等待和进度跳转。Node.js 仅用于此项开发测试。

修改 MuJoCo 或 Go2 任务切换后，运行 `node --test tests/task-tabs.test.cjs`，检查默认任务、暂停旧任务、键盘操作与直接任务锚点。视频进度和视角保留仍需在真实浏览器中检查。

修改首屏示意动效后，运行 `node --test tests/navigation-illustration.test.cjs`，检查手动暂停、离屏暂停、标签页可见性和减少动态效果设置。

首播需在真实浏览器中验证。先启动测试预览：

```bash
python3 tests/playback_preview.py --port 4174 --mbps 8
```

在 Chromium 或内置浏览器中，每轮先打开 `http://127.0.0.1:4174/__cold-start`。此测试入口发送 `Clear-Site-Data` 响应头，清除本地测试站点的缓存与存储。然后点击对应任务链接，立即点击播放并等到结束。Safari 使用全新的私密窗口。两项任务分别清缓存测试。另测正常浏览路径：清缓存后先打开首页，停留约 15 秒，再播放 Go2；确认点击前已下载视频、没有自动播放，点击后不重复下载。测试预览将所有录像的总带宽限制为 8 Mbps，播放期间允许保存新下载的分段。不能把刷新已播放的页面当作首次访问。

播放结束后，在另一终端读取本轮指标：

```bash
python3 tests/playback_report.py http://127.0.0.1:4174
```

确认两路均开始播放、任务播放到片尾，并检查首次等待时间、播放中等待次数、实拍跳转次数和双路最大偏差。慢网测试可把 `--mbps` 改为 `4`；改变参数后重新启动测试预览。测试脚本与指标不会发布到官网。

## 核心能力展示

打开 `/#capabilities` 查看三项 Agent 能力：任务内记忆、途中目标监测、选择性调度。桌面为三列并排，间距 24px，卡高 340px、内边距 24px；800px 及以下为单列，卡高 300px。每卡图外保留一个短标题和一句说明，SVG 内没有可见文字、流程框、箭头或实拍拼图。三段已确认的等距微场景保持原造型、配色和时序；记忆片段保留门、沙发和走廊的微缩轮廓。真实边界与文档链接统一收进默认折叠的“技术说明”。

能力区不使用 Tab；MuJoCo 和 Go2 的视频任务切换保持不变。桌面可见动画按 6 秒循环，悬停或键盘聚焦突出当前图像，不降低文字透明度。手机只播放可见内容区中央最近的一项，其余静态可见。点击画面可暂停；手动暂停、离屏、后台标签页及系统减少动态效果均受支持。修改后运行 `node --test tests/*.test.cjs`，同时检查图内可见文字为零、三卡全部可见、技术说明默认收起和手机无横向溢出。

全站内容与导航最大宽度统一为 1200px，相邻章节实际间距为 96px，主章节标题全部左对齐。项目介绍桌面左栏为 360px 的吸附标题，栏距 50px，右栏完整保留五段正文与中译；段距 24px，各段前仅一个 6px 圆点。800px 及以下改为单列，标题取消吸附。

手机导航固定为 96px 两行：第一行 56px，保留品牌和语言按钮；第二行 40px，五个链接单行横滑，不换行或隐藏入口。章节锚点继续使用实际导航高度避让。

## 修改内容

前端风格以 [AGENTS.md 的风格基线](AGENTS.md#前端风格基线2026-10-22-用户确认) 为准：暖灰绿背景、纯白卡片、鼠尾草灰绿与烟灰蓝点缀，以及轻微阴影，保留 16px 圆角、悬停反馈与布局。后续扩展沿用这版；具体配色、尺寸、回放布局和双语规则集中维护在该约定中。

## 网页字体

演示区采用轻量目标选择器，不显示 Task 编号与重复任务标题。决策文字为 14px，时间标签为 12px；桌面在等高面板内滚动，窄屏完整展开。Agent + VLN 标题旁不显示剪辑说明入口或浮层；素材剪辑记录保留在本文档中。

英文使用 Inter，中文使用 MiSans VF。字体在 `media/fonts/` 自托管，不依赖设备预装或访问外部字体服务。其余字号、字重、间距和布局沿用上一版。

MiSans 使用[小米官方网页字体服务](https://cdn-font.hyperos.mi.com/font/css?family=MiSans_VF:VF:Chinese_Simplify,Latin&display=swap)提供的原版 WOFF2 切片。脚本只选择覆盖页面文案的官方文件，不修改字形、内部名称或字库内容。完整许可见 `media/fonts/misans-license.pdf`，使用说明见 `media/fonts/NOTICE.txt`；页脚注明 Inter / MiSans。字体不适用本站源码的 Apache-2.0 许可。

Inter 使用官方 `rsms/inter` v4.1 可变字体。更换字体来源前重新核对许可，不将免费商用等同于可以改编或单独分发字库。

新增页面或任务文案后，在仓库根目录使用 Python 3.10+ 更新字库文件选择：

```bash
python3 prepare_fonts.py
```

脚本仅依赖 Python 标准库。首次下载字体与官方 CSS 至 `.runtime/fonts/`，之后复用缓存；输出包含内容哈希，只清理本脚本生成且已替代的文件。浏览器根据官方 Unicode 范围按需加载切片。将 `media/fonts/` 的变化与文案一同提交。浏览或部署网站不需要 Python。

表格比较 LightNav 与 Agent + LightNav，列为 SR（百分数）、SPL（0–1）和 LLM-judged SR（百分数）。**所有当前数值均为用户要求的布局示例，不是实测或官方成绩。** 保留表格上方的双语 mock 说明；换入完整实测结果后再移除。同步补充评测版本、split、任务数量和实验设置，不将各基准的分数直接横向比较。R2R / RxR 是否采用连续环境版本尚待确认；HM3D v2 对应官方 `objectnav_hm3d_v2.zip`（HM3DSem-v0.2）。

场景中可能有多个符合指令的同类目标，如椅子、电视或桌子。当 SR 绑定特定标注实例时，其他有效目标可能不计成功；不能将这一限制泛化到所有基准。LLM-judged SR 根据原始指令和最终画面，从语义上补充评估任务是否完成，不替代官方 SR。评审模型须独立于导航 Agent；两组使用同一评审模型、提示词、判定标准与任务集合，以保证比较公平。发布时注明独立评审模型及其设置。不确定计失败并单列，API 错误先补评，不能删除失败任务。R2R / RxR 的过程性要求不能仅靠最终画面判定。

SPL 同时衡量成功与路径效率。探索可能延长路径并导致部分 SPL 下降，但不代表每次下降都来自有效探索。换入实测分数后，结合轨迹说明原因，不根据示例分数下结论。页面将这些必要说明收进“评测口径”。
