把寻找的过程交给机器人

“找到棕色沙发。”你知道自己要找什么，却未必知道它的准确位置，也不一定能给出明确的路线。Navigation Agent 围绕这样的需求展开：你用自己习惯的方式描述目标，机器人开始在周围的空间中寻找，不需要你事先安排每一步前进和转向。

目标不一定出现在任务开始时的画面里。机器人可能需要先看看周围，走向房间的另一侧，或根据新看到的线索继续寻找。Agent 在这个过程中持续围绕最初的目标，根据机器人看到的环境判断该如何继续。

走到一个位置也不意味着任务就此结束。Agent 还会再次观察，确认眼前的物体是否符合你的要求。从接收目标、展开寻找，到确认结果，整个过程都围绕你最初想完成的那件事。

Navigation Agent 将 Agent 的回应带入真实空间：面对一个请求，它会在机器人所处的环境中展开观察与行动。自主找物是这个产品的起点，把一个日常的需求变成机器人可以执行的任务。
