Navigation Agent

告诉机器人， 你想找什么。

Navigation Agent 是一个面向机器人的自主导航 Agent。用日常语言告诉它你的目标，它会引导机器人观察周围、探索空间，寻找你想找的东西。

GitHub ↗ 技术文档 ↗

从一句日常表达开始。

“找到棕色沙发。”你知道自己要找什么，却未必知道它的准确位置，也不一定能给出一条明确的路线。Navigation Agent 围绕这样的需求展开：你用自己习惯的方式描述目标，机器人开始在周围的空间中寻找它。

人与机器人的交流由此围绕一件具体的事情展开。你不必把“找到沙发”拆成一连串前进和转向的指令，而是直接说出想完成的事，让机器人围绕这个目标行动。

把寻找的过程交给机器人。

目标不一定出现在任务开始时的画面里。机器人可能需要先看看周围，走向房间的另一侧，或根据新看到的线索继续寻找。Navigation Agent 在这个过程中持续围绕最初的目标，根据机器人看到的环境判断该如何继续。

走到一个位置也不意味着任务就此结束。Agent 还会再次观察，确认眼前的物体是否符合你的要求。从接收目标、展开寻找，到确认结果，整个过程都围绕你最初想完成的那件事。

让 Agent 走进真实空间。

Navigation Agent 将 Agent 的交互带入机器人能够行动的空间。面对一个请求，它的回应是在周围环境中展开观察与行动。自主找物是这个产品的起点：从一个具体、日常的需求出发，把人的目标与机器人的行动连接起来。
