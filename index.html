    From a goal to exploration

    “Find the brown sofa.” That tells the robot what you want, but not which room the sofa is in or which route to take. If the target is out of sight, the robot still needs to decide where to look first, which clues to follow, and when to try another direction.

    Navigation Agent makes these decisions. It observes its surroundings and considers both the goal and the places it has already explored to choose where to look next. When the target is not visible, it can first move to a position that offers a better view. When it spots a possible match, it can move closer to inspect the details. You do not need to provide a new instruction for every step of the search.

    The agent and VLN have distinct roles. The agent decides where to go next and why, then turns that decision into a concrete instruction for the next local destination. VLN uses the instruction and visual input to generate navigation actions for the robot to execute. The project currently integrates LightNav for this navigation stage.

    After each navigation step, the agent observes the environment again and checks for progress against earlier clues and action results. If it has gained no new information, it adjusts the direction of exploration. If it finds the target, it checks whether it matches the request. Finishing one navigation step does not by itself mean the whole task is complete.

    Together, these capabilities let you simply ask the robot to find something. The agent handles observation, decisions, and adjustments throughout the search, while VLN provides the navigation needed to carry out each step.
